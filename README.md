# Europa Mission Design

I'm designing an end-to-end mission to Europa, starting with the Earth to Jupiter transfer. I built a Lambert's Problem solver in MATLAB using Gooding's method, chosen for its consistent convergence at near-singular transfer geometries and support for multi-revolution cases. I validated the code against 17 test cases that covered many different orbit scenarios. I'm currently finishing up a porkchop plot generator to identify launch windows that balance departure C3 and arrival V∞.
